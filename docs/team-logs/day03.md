## 今天遇到的问题及解决过程描述

今天主要完成了前后端接口联调及项目依赖修复工作。马哲宇在对接登录注册 API 时发现，原有前端代码仅为模拟数据提交，通过重构 login.js 和 register.js 改用 `fetch` 异步调用后端 `/api/auth/login` 和 `/api/auth/register` 接口，实现了真实的数据交互，同时将用户信息存入 sessionStorage 以便后续页面使用。在构建过程中发现 pom.xml 中 `spring-boot-starter-webmvc` 依赖坐标错误，修正为 `spring-boot-starter-web`，并补充了 `spring-boot-starter-security` 和 `spring-boot-starter-validation` 依赖，同时修正了测试依赖配置。application.yaml 中配置了 MySQL 数据库连接参数与 JPA 自动建表策略，确保项目正常运行。此外，用户名正则规则增加了对中文的支持，提升了系统的适用性。

田天乐对数据库需求分析进行了更新，优化了第一版数据库表结构，新增了管理员表以支持后续权限管理；同时完成了前端页面的基本框架搭建。黄开元完成了后端功能模块到前端的映射，实现了从登录注册页面到功能页面的跳转，页面风格保持统一，为后续业务功能开发做好了准备。
